# 10｜驗收清單與重播測試

以下案例用於核對程式是否正確遵循已定規則；若資料缺口未回查，測試應被標記 `PENDING_SOURCE` 而非填假預期值。

## 時間與事件

- [ ] `world_time` 每 72T 換一天；前48T白天、後24T夜間。
- [ ] 小動作耗 1T，大動作耗 3T；10 人各有 `next_action_at`；某人採集時他人可以進行三次小動作。
- [ ] 同時刻行動以速度決定先後；任何裝備速度值**不縮短**下一次行動等待。
- [ ] 夜間 24T 之內**8 次**環境危害檢查（每3T），營火保護所在 Node。
- [ ] 夜蝙蝠、夜狼的區域檢查為**所有沒有點燃營火保護的 Node**，包括普通營地、港口等；只因 Node 名稱不能跳過夜間危險檢查。已點燃營火所在 Node 免除夜間環境危害，但不免 PvP 或主動怪物戰。
- [ ] 夜蝙蝠與夜狼的具體出現率仍為 `PENDING_SOURCE`；不得默默指定各50%或當成地牢普通怪事件率。
- [ ] 物品在 t=71 落地，到 t=72 仍存在；到 t=143 剛好經過72T才過期。不可午夜批次刪除。
- [ ] 未開的寶箱/背包適用同一物件個別 72T 到期。
- [ ] 每日三椰子沙灘各 +1，上限各3；已在沙灘上未採收的椰子**不過期**。
- [ ] 食物腐敗天數3、普通可食用前置飽食<5、吃後可能飽食>5。

## 社交與模型

- [ ] 發公開短訊消耗**1T**，發話者可依獨立等待繼續活動。
- [ ] 收件者下次行動收到內容，閱讀不消耗動作；可以不回覆，回覆消耗1T。
- [ ] 同 Node 可見的旁觀者能讀到公開訊息；**不得套用舊私密聊天流程**。
- [ ] 沒有握手、進聊天室/接受/等待聊天室或任意免費長談 API loop。
- [ ] 交易請求及回應消耗動作，原子移交物品，重試不複製。
- [ ] AI 看得到別人手上/身上的物件，看不到別人背包精確內容與 HP。
- [ ] 模型只能選合法動作，不能以文字聲稱自己找到裝備就直接更新資料庫。

## 怪物與傷害數學

- [ ] 玩家 ATK7／怪物DEF1 → **傷害6**；怪物原傷7／玩家DEF8 → **傷害0**。
- [ ] 森林野豬與山羊具有相同基準 HP10／DEF0／SPD2；普攻分佈 1:50%、2:35%、3:15% 合計100%。**生成機率未設定**；不得讓它替代夜蝙蝠/夜狼的全域危險。
- [ ] 鐵劍5打 HP8 DEF1 綠矮人 → 兩擊4+4殺死，**不召喚**。
- [ ] 木劍3打同怪 → 每擊2，進入HP2仍存活時**召喚一次**，召喚者不可再召喚。
- [ ] 管道巨鼠單次出手**2次獨立抽傷**，玩家防5下期望失血 **0.9/次出手**。
- [ ] 第三層火蜥蜴26HP/0DEF：騎士劍7需**4擊**；怪若出手3次、對防8期望失血**9**。
- [ ] 熔岩史萊姆24HP/1DEF，騎士劍7需**4擊**；四次反傷**包括致死一擊**，全騎士防8反傷期望 **1.6HP**。
- [ ] 熔岩史萊姆的普通攻擊**與反傷同時計入**，不能互相覆蓋。
- [ ] 火翼蝙蝠18HP/1DEF，騎士劍7造成6×3，未在存活時降到5.4以下，**不召喚**。
- [ ] 火翼蝙蝠與管道巨鼠皆**每次出手兩擊**；原始傷害每擊重抽。
- [ ] 食人花的吞食只針對 HP**嚴格小於10**的對象，HP恰好10不可被直接吞。
- [ ] 大貓爪勝利累計**5次突破**；存在20%命中率參數，但適用於哪方須以原 Q 回查；不創建假 HP 條。
- [ ] 大金剛鸚鵡飛翔/嘲諷/啄擊行動機率總和100%，嘲諷被打即時反擊但不可同時一般攻擊。
- [ ] 巨龍75HP被勇者劍15**五擊**；龍息傷害同 Node 全員，物品龍血僅最後一擊者得到，治療+10。

## 地圖與事件池

- [ ] 地牢各層的**事件池 CSV 機率合計 100%**；前三種直遇怪合計**50%**。
- [ ] 第二層濕滑水道額外 11% 可強制遇黏液怪，不是從50%扣11%。
- [ ] 第三層火山彈**只**在A1/B1/C1出現，勇者系列與背包不受損。
- [ ] 非 Boss Node 原本無其他島民進入必定一事件；已有島民時不為每名入場者重抽。
- [ ] 同 Node 多島民進戰場，怪物每次攻擊隨機選活目標，龍息則群體。
- [ ] 獨立 Boss、樓層解鎖，退出地牢路線進度重置，樓層權限照規則分配給存活在場者。
- [ ] 釣魚主池 `40+25+5+5+5+20=100`；雜物分拆12+4+2+2=20（**整體率**）。
- [ ] 岩石資源池5+5+90=100；夜間岩石傷心40%與睡眠減損25%可同時中獎。
- [ ] 夜間河流/岩石**連續三次**，共耗9T，離開/中斷重算。
- [ ] 全域勇者唯一性：背包、裝備、地面、屍體、可找回物件都不重複生成；銷毀後才可能回歸來源。
- [ ] 隨機種子與事件結果可重播，死後傳記不會改動核心客觀紀錄。

## Q1–Q43 提示詞與 Node 報幕驗收

- [ ] 十名模型收到**完全相同的中文報幕＋JSON格式**；每次歷史中只保留**最新一份**當前 JSON，並可自然截斷最舊經歷。
- [ ] 只有 `action_id` 是執行依據；`intent` ≤30字；發話／寫字 `text` ≤50字；不得在 JSON 之外輸出多餘文字；API不啟用強制JSON模式。
- [ ] 報幕完整保留該輪 Node 可觀察事件、依引擎結算順序一句一句陳述，不重寫因果、不提供移動建議、隱藏裝備數值與策略。
- [ ] `1.1` 本輪抵達中央營地，`2` 本輪吃椰子，`3.3` 持續睡覺但不出動作：報幕必有「你來到了中央營地」「2吃椰子」「3.3正在睡覺」三種內容。
- [ ] 若 `1.1` 仍在 Node 間移動中，**不收取**任一端 Node 事件、公開發話、沿途物件資訊。
- [ ] 無 `combat` 欄位或戰鬥狀態；敵對動作只會改變本輪合法行動清單。`visible_actors.type` 值域限 human/animal/monster。
- [ ] 島民外貌門檻 HP≤5「狀態不好」、飢餓「面黃肌瘦」、睡眠資源耗盡「黑眼圈」，不洩漏別人 HP/飽食/睡眠實際數值。
- [ ] 時段僅自然中文提示，JSON 不帶精確世界時間；合法動作仍有整數 `time_cost`。
- [ ] 文字牌內容**只有READ行動真正完成**才出現在中文報幕，靜態 `items` 只含物件名稱。
- [ ] 呼叫錯誤最多兩次額外重試；JSON格式/合法性錯誤不重試，愣神1T，下一次中文報幕與 `last_action.result` 按定案回報。
- [ ] 原模型失聯切備援，備援10次**有效行動**後再測原模型；模型切換不得新增人格、丟失個人狀態或補造已發生事件。
- [ ] 歷史客觀事件按 Node/島逐輪存檔；個人 intent 保留至死亡產生評價，但不得把 intent 偽裝成客觀事件。

## 長期平衡（只檢驗，不先強行改值）

- [ ] 隨機 Bot 模擬多個遊戲日，統計各階段死亡與資源回補；**平均30天**僅是歷史測試參考，不是強制死亡線。
- [ ] 驗證正式新版等待制下鐵級、騎士級、勇者級戰鬥實際出手次數及 HP 消耗（不能直接套用舊24輪版）。
- [ ] 月費用上限US$20有實際阻斷，報告模型呼叫、token與成本可查。

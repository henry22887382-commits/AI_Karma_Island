# 02｜72 T 時間、等待排程、同時事件

## 正式時鐘

【定案】`1 day = 72 T`, `daylight = 48 T`, `night = 24 T`。舊的 24 輪／天及 1/3 分數時間已全廢；目前所有系統一律以**整數 T**紀錄。

| 分類 | 耗時 | 已確定例子 |
|---|---:|---|
| 小行動 | **1 T** | 對話發訊/回訊、物品移動與操作、交易請求/回應、攻擊、戰鬥道具 |
| 大行動 | **3 T** | Node 地圖移動、採集、一般場景探索與互動、釣魚/潛水/岩石探索 |
| 等待 | **1 T** | 使用者已明確決定 WAIT=1T |
| 危險區睡眠夜間遇敵檢查 | 每 **3 T** 結算 | 一夜 24/3 = **8 次**；依所在 Node 地形率，規則見 06 |
| 物品過期 | 普通地面物落地/生成起 **72 T** | 未開容器亦同；use放置的場景物永久存在、只能破壞移除；固定營火例外見04 |

## 等待排程演算法（由定案直接展開）

1. 每名 AI 與戰鬥怪物有獨立的 `next_action_at`；同一個世界有單調遞增時間。
2. 引擎挑**最早**可以動作的參與者，不要求其他人同步完成一輪。
3. 角色在 `t` 執行行動後，按動作成本把下一次可行動時間排至 `t+1` 或 `t+3`。不要把這當成所有人的『世界輪』一起 +1。
4. **速度**只在 `next_action_at` 相等時決定先後順序；速度快不會縮短冷卻、移動時間或攻擊間隔。
5. 同一時間多名角色：先速度；同速依 HP、飢餓度、睡眠資源、攻擊、防禦、空背包格數依序降序；上述指標完全相同時，以已記錄的 seeded draw 決定順序。跨居民／怪物也沿用同一順序，來源見 `decisions/ENGINE_DECISIONS.md` 與 `engine/tie-break.ts`。
6. 定時更新（世界日界線、夜間風險、掉落物到期、椰子產量、睡眠日結算）是世界事件，不能因某 AI 不行動而忘掉。
7. 死亡者退出排程；新代次使用新獨立實體，不沿用死者冷卻與模型上下文。

## 目前實作邊界（2026-10-22）

- 環境互動沿用大行動 **3T** 成本，角色結算後的下次行動時點為 `t+3`。目前handler在該行動結算時立即套用效果；沒有持續中的interaction狀態欄位，也沒有「3T後才完成效果」的延遲完成機制。因此這是行動成本／再次行動門檻，不代表角色在互動狀態中持續等待。
- 移動仍為3T；出發結算時離開起點並進入 transit，直到 `t+3` 的抵達timer才歸屬目標Node並抽一次該區域事件。Transit期間沒有目前Node，不能被起點或目的Node的居民／怪物當作同Node目標，也不會收到任何Node觀察內容。抵達前已存在於目的Node的玩家會抑制入場事件。攜帶中的屍體／戰利品隨居民 transit；一般地面物件留在原Node，仍按各自72T時點到期。
- 所有進入／離開相關事件共用「Node是否有存活玩家」判定：玩家進入已有其他玩家的Node時不抽入場事件；最後一名玩家離開或死亡後，清除該Node的敵對或可狩獵生物actor。地面物件不屬於actor，不因Node無玩家而清除；非唯一物品仍按各自生成時間滿72T到期。位置由地牢Cell追蹤的actor不視為地表Node occupant。

### 範例【推導】

在 t=10，A 採集，B 打一拳，C 發訊：A 下次 t=13，B/C 下次 t=11。t=11 可輪到 B/C 繼續行動；A 不得搶先。若 B/C 同時動作，使用角色速度排序。

## 對話的最新正式模型

- 發話本身即一次 1T 小行動；沒有 TALK 握手/對話鎖定/接受/拒絕/免費說話等階段。
- 內容是**公開的短訊**；發話者下次按照自己 `next_action_at` 繼續決策。
- 收件者於自己的下一次環境資訊獲得該訊息，可選擇回覆或改做其他事；回覆又是一個 1T 小行動。
- 公開資訊應併入可見事件流，讓旁觀者可察覺；**是否跨 Node 全島同步公告尚未有明確規格**，不可偷偷實作全島心靈通話。見 11。
- 發言、交易**都不免時間成本**；這是限制 AI 過度發話的主要機制，不需要另設聊天次數上限。

## 從舊時間系統的換算

| 舊尺度 | 新尺度 |
|---|---|
| 24 舊輪／天 | 72 T／天 |
| 白天 16 輪 | 白天 48 T |
| 夜間 8 輪 | 夜間 24 T |
| 舊小行動 ⅓ 輪 | 1 T |
| 舊大行動 1 輪 | 3 T |
| 原一天地面物品壽命 24 舊輪 | 72 T（物品個別起算） |
| 夜間每舊輪一次危險 | 每 3 T 一次 |
| 夜間三次連續互動 | 三個大動作 = **9 T** |

## 不可誤用

- 『怪物需 3–5 回合被擊敗』說的是**交手/攻擊次數**，不再表示 3–5 世界 T 的戰鬥必然完結。
- 舊檔推導 `10 人×24 輪＝240 呼叫/日` **不適用**；現在的實際 API 次數依大小動作混合及非同步訊息頻率而變。
- 傷害及狀態速度 `round(current HP / 10 + equipment modifiers)` 與 `next_action_at` 分離；例如披重甲可失去同時間優先權，但**不因此攻擊更慢**。

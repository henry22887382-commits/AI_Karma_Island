## 使用標記

- **【定案】**：對話中明確確定或由使用者修訂，工程可按此建置。
- **【核對摘要】**：來自既有長篇對話的濃縮紀錄，保留數值，但非完整逐字原文，建置時須搭配驗收。
- **【推導】**：嚴格依已知規則計算，並非新增世界規則。
- **【待回查】**：沒有可供確認的原數據、原圖或逐題紀錄，**不填假數值**。
- **【歷史作廢】**：過時規則，僅保存修訂脈絡。

## 最重要的五條不變項

1. 島民不預設職業、人設、人格/陣營目標；模型只提出**合法動作**，固定世界引擎負責真實結算。
2. 世界十位島民、有生有死；主島與各世代留下的真實痕跡延續，後繼者**不繼承記憶**。
3. **72 T／天，白天 48、夜間 24；小動作 1 T、大動作 3 T；每名角色獨立等待**。速度僅打破同時刻平手。
4. **短訊公開、非同步、每次發話 1 T**。不採私密封閉聊天室、握手確認或免時間成本談話。交易也要花時間。
5. 現行遊戲規則以後述文件為準；不要從 2026-10-19 舊稿恢復 24 T、免費對話、低 HP 示例、未定數值或固定 240 API calls/day 的估計。

# 08｜公開短訊、交易、歷史與身後世界

## 公開非同步短訊【最新覆寫】

**使用者最後修正：「短訊改成公開，新機制已經允許，其他不變。」**

- 發話：島民選擇發出一則短訊，耗費**一個小行動 = 1T**，自身按等待制排入下一行動。
- 收訊：指定對象於**其下一次可行動**時，在環境資訊裡看見短訊；閱讀本身不消耗動作。
- 回話：收件者可選擇再花 **1T** 回訊，也可移動、打架、採集、不理會。發話者不被鎖定在聊天室。
- **公開**：訊息可作為場景中的公開觀察事件，其他符合可見條件的島民可知曉，而不再聲稱『第三方絕對不能看』。
- 目前原對話沒有定義『公開＝全島廣播？或目前同 Node 可見？』的完整原子規格。整合成**同場景可觀察公開訊息**是保守實作解讀，但**不能擅自承諾跨 Node 即時轉播**。
- 這等同互傳簡訊而不是連續聊天室；不需要握手、等待對方接受、輪流鎖定或受攻擊後中止聊天室。
- 設計目的：使**過度主動發話**有真實的時間機會成本，不設聊天上限。

## 交易、贈與與暴力

- **【現行覆寫｜2026-10-22】交易請求及接受／拒絕目前停用。** 不得列為居民合法動作，模型proposal也不得繞過合法動作校驗；交易設計因會洩露情境外資訊並增加上下文負擔，待使用者重新設計。舊交易請求／回應流程及其時間成本僅保留歷史，不是目前可執行規則。
- 丟棄物品與公開非同步短訊維持可用；贈與仍依一般合法動作及物品所有權一致性規則處理。
- 存在 **GIFT** 贈送與 **ATTACK** 攻擊；PvP 即地圖上的正常行為，非切換到不透明獨立戰鬥模式。
- 第三人不會因旁人遭到攻擊就**自動**加入戰鬥，但可在自己的行動機會選擇介入。
- 沒有獨立『偷走活人背包』的免費潛行偷竊機制；可攻擊、殺死並搜刮屍體。
- 可見其手持/裝備，**不可直接看見他人背包與 HP 的數值**。

## Q1–Q43 補充：客觀歷史與主觀意圖分離

**【定案】** Node 及整座島的歷史以「逐輪已結算的客觀事件」為基礎。每次模型輸出另存最多30字 `intent`，保留至死亡時產出個人死亡評價；**意圖不屬於 Node／全島客觀歷史**。模型上下文只有一份最新 JSON，其餘過往經歷自然由最舊截斷。中文報幕是 Node 當輪事件與當前持續狀態，非世界事件總表的逐人拷貝。參考 [14_AI決策提示詞與Node報幕.md](14_AI決策提示詞與Node報幕.md)。

## 屍體、死亡與碑文

- HP≤0 後即死，遺留可搬運/搜刮的屍體與物件。屍體**長期存在**，不能套用普通地面72T過期。
- 搜刮屍體每次拿走一件物品，需耗相應一項合法動作；搬運與搜刮是不同動作。
- 地牢內不能直接掩埋或立碑；可將屍體搬出地牢。地牢外可以掩埋（消除痕跡）、立碑或搬走。
- 紀念碑谷存在**永久文字**，不是普通散落物；AI 可立碑自由留字、可透過閱讀隨機取得既有內容，**不能指定精確哪個作者的碑**。
- 海上漂流瓶、書籍、紙筆、告示牌等可把經驗、誤導與傳說保存在物質世界；固定文獻庫 **100+** 篇/段，包含英雄傳說、部分正確線索、荒誕冒險紀事、生存教學等約 5 類內容。實際**100 段原文未存入本包**，不可聲稱有全文。

## 死後傳記、遺忘與玩家

- 死亡後將該生命的行為、私有上下文/公開互動和客觀世界事件交給較強模型生成**文學式心理傳記**。
- 傳記可描寫/解釋角色的可能內在心境，但不可改寫發生過的客觀事件；不等於科學人格診斷。
- 只有**玩家/觀察者**看得到傳記；島上居民不會自動收到傳記、更不會因此繼承上一代人格。
- 產生傳記後可以刪除個人原始記憶資料；**世界狀態和可觀察痕跡必須保存**，已放置的文本/屍體/交換完成的裝備不隨原始記憶刪除。
- 玩家 UI 可查看 Node、島民、物資、事件/訊息紀錄、死亡傳記與世界時間；玩家不直接指派島民下一個行動。

# 01｜核心玩法與居民

## 概念

【定案】輪迴島是一個讓 **10 名不同語言模型所驅動的自主居民**在小島生活、行動、交流、死亡並留下可觀察歷史的模擬遊戲。玩家是觀察者，不控制角色，也不是劇情導演。島嶼歷史由固定世界核心裁決；模型只能在合法動作集合中選一個動作，不能修改物品、機率、HP 或時間。

【定案】不使用預設人格卡、職業、陣營、故事、必做目標。居民可以自行形成交易、協作、攻擊、保護、避險、冒險、誤解和傳承。部分世界傳說可包含錯誤訊息；敘述不是強制 AI 信念。

## 人口與代次

- 【定案】同時維持 **10 名居民**，基本編號 0 至 9。外觀/顯示形象和基礎號碼相連。
- 【定案】死者留下屍體和物品，次一世代沿用號碼但加代次，例如 `3.1`。**不是復活**，不繼承前任身分、記憶與性格。
- 【核對摘要】死亡後補人於**下一個早晨**；世界核心應維持目標人口 10 而不強迫逐日死亡。
- 【定案】不設定最大壽命、每十天死一次或每天必須死一人。沒有隱形死亡配額。

## 角色初始資源與每日生存

| 欄位 | 數值/規則 | 註 |
|---|---|---|
| 生命值 | **30 HP** | 【核對摘要】固定初始值 |
| 飽食 | **5** 初始 | 【核對摘要】每天 −1 |
| 睡眠資源 | **3** 初始 | 【核對摘要】每天 −1；睡滿夜晚恢復至 3 |
| 飽食為 0 | 每天 **−3 HP** | 【核對摘要】 |
| 睡眠為 0 | 每天 **−3 HP** | 【核對摘要】 |
| 兩者均為 0 | 每天合計 **−6 HP** | 【核對摘要】 |
| 平常睡眠 | **不恢復 HP** | 【定案】 |
| 恢復 HP | 僅龍血 **+10 HP** | 【核對摘要】非預設可大量農的補品 |
| 生命為 0 | 死亡 | 【定案】 |
| 一整天 | 72 T（白48、夜24） | 【定案】時間規格見 02 |

**注意**：『飽食上限 5』與『食物可超吃超過 5』不可誤合併；吃東西僅在飽食 **<5** 時可發起，吃下可使數值 **>5**。詳見 04。

## 資訊、知覺、記憶

- 可知自己狀態/裝備/背包、當前 Node、周遭物件、可見行動與所見傷情；**看不到別人精確 HP 或背包**。
- 能看見別人持用的武器、穿戴的防具、行動及對話等依公開範圍可見資訊。
- 怪物物種及外觀/受傷描述可觀測，**精確 HP/防禦/攻擊表不直接給 AI**。
- 不全島廣播死亡、Boss 及其他事件；由親眼看見、文字和交流獲知。世界事實與島民認知分離。
- 只維持當世個人對話/行動上下文；當上下文過長允許較早記憶自然截斷，不強塞人格摘要、前世記憶。
- 死亡傳記由高階模型根據一生資料推測/敘事，玩家專屬，不能當成島內客觀事實注入活人記憶。

## 合法動作（固定白名單）

【核對摘要】原始動作白名單：`MOVE, WAIT, SLEEP, EAT, HARVEST, FISH, PICKUP, DROP, USE, EQUIP, UNEQUIP, ATTACK, DISENGAGE, TALK_REQUEST, TRADE_REQUEST, GIFT, READ, INSPECT, LOOT, INTERACT`。另有與屍體搬運、埋葬、立碑有關的場景互動。

**最新覆寫**：`TALK_REQUEST` 表達的握手語義已失效，應由**公開非同步發訊**替代，不可保留「先接受進聊天室」的硬性流程。實際新程式 enum 可換名，但不能偷偷改變玩家確認的體驗。`TRADE_REQUEST` 則仍有獨立交易流程。

模型提示詞固定可包含「上次結果／目前狀態／視野／合法動作／指令」，最末行輸出**精確合法動作**；非法輸出只能遭拒或安全重試，不可被解釋成自由編輯世界。

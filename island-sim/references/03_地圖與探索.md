## Node 物理與資源原則

- 同 Node 的居民可以互動、戰鬥、交易與看到場景事件；角色精確 HP、背包內容並非公開。
- 普通掉落或事件生成的地面物品與未開啟容器，各自於**生成後完整 72T** 消失且可拾取；午夜不會觸發一鍵刪除。經常規 use 放置到 Node 的告示牌、營火等場景物永久存在、不可拾取，只能破壞移除。
- 掉落的四件勇者裝備不適用普通過期；屍體保留；紀念碑谷永久存字。
- **三處椰子沙灘**：每處每日生產 1 顆，最多可存 3 顆，未採收自然椰子不過期（詳 06）。
- Node 功能由場景設計決定；Node25 中央營地預設有一個已點燃營火，沒有預設到期時間；中央營地以外的地名本身不自帶安全效果。任何地表 Node 有有效點燃營火時，抵達該 Node 不抽白天或夜間入場事件池，夜間環境遇敵及每 3T 睡眠檢查也跳過；營火不免疫主動探索、PvP 或普通戰鬥。營火的地表規則不延伸到地牢 Cell。詳見 06。

## 火山地牢

【核對摘要】共有**三層**，每層為**三條分支**，每層最短需要 **3 次 Node 移動**抵達該層 Boss。最底層終點是巨龍。

- 非 Boss Node：當**沒有其他島民**的地點被進入時，100% 觸發**一個**該層事件；其中一般怪物直接遭遇占 50%。
- Node 已有其他島民時，不可當作每名後來者都重新抽一份獨立事件。
- 遭遇怪物時，Node 內所有在場島民直接進入同一場戰鬥；不是由一人私有的隔離戰鬥畫面。
- Boss 格本身是該樓層同一個 Boss 事件：進入時 100% 觸發，不抽非 Boss 隨機事件池，沿用既有 Boss 戰鬥規則。
- 離開 Boss Cell 視為向後撤退：同一 `(trip, floor, cell)` 還有島民時 Boss 保留；最後一名島民離開或死亡使該 Cell 無人時，清除該 Boss 及戰鬥進度。其他 Cell 的島民不影響此判定。之後再次進入仍觸發相同 Boss 格事件並使用相同戰鬥規則；撤退不算通關、不解鎖或移動到下一層。
- 撤退抵達來路前一 Cell 時，仍依該 Cell 入場事件與 occupancy gate 正常結算一次；不因撤退而跳過，也不重複抽取。
- 擊敗樓層 Boss 後，該 Boss Cell **所有仍存活的島民**直接移到下一層起始格 S。無法歸給擊殺者的通關掉落放在新起始格地面，依物品自己的生成時間保留 72T。這是勝利轉層，與撤退分開處理；第二層的特殊勝利/撤退機制見 05。
- 每層三條分支起始格 A1、B1、C1 均可離開地牢並返回火山入口 Node 21；退出後再次進入應重做樓層進度，不能把上一趟路線推進偷留成永久捷徑。
- 正在戰鬥可**後退至來路**（不是戰鬥中直接往前穿透敵人）；**第二層黏液怪特殊禁止撤退**。
- 地牢內屍體可搬走、搜刮；不可直接掩埋或立碑；外部場景允許相應屍體處理。

## 地牢第一排的特例

第三層第一排 Node：**A1 / B1 / C1** 可能觸發火山彈；此事件只破壞一件**手持普通物品**，不破壞背包內容和所有勇者系列裝備。其他第三層 Node 不可產生火山彈。非第一排移出的8pp依D-007均分到灼熱泉水、遠古寶箱、探險者遺物；見07及11。

## 特殊探索連續條件

| 地點／行動 | 條件 | 效果 |
|---|---|---|
| 夜間河流潛水 | 夜間**連續 3 次**探索，不中斷 | 獲得勇者上甲（若尚未存在/可生成） |
| 夜間岩石探索 | 夜間**連續 3 次**探索，不中斷 | 獲得勇者盾（若尚未存在/可生成） |
| 釣魚 | 特定低機率物品池 | 可能取得勇者下甲 |
| 地牢第三層火蜥蜴 | 擊殺並符合唯一存在條件 | 取得勇者劍 |

連續探索的『3 次』是**三個大行動**，因此至少 **9T**；更換行動、離開現場或跨日會重置連續紀錄。【待回查】「夜間潛水」的具體節點原 ID 與場景完整進入觸發表。

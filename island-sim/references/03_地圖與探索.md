## Node 物理與資源原則

- 同 Node 的居民可以互動、戰鬥、交易與看到場景事件；角色精確 HP、背包內容並非公開。
- 地面普通物品與未開啟的事件容器，各自於**生成後完整 72T** 消失；午夜不會觸發一鍵刪除。
- 掉落的四件勇者裝備不適用普通過期；屍體保留；紀念碑谷永久存字。
- **三處椰子沙灘**：每處每日生產 1 顆，最多可存 3 顆，未採收自然椰子不過期（詳 06）。
- Node 功能由場景設計決定；**夜間風險每 3T 檢查，夜間蝙蝠與夜狼屬所有非安全 Node 共通危險**。**安全區只有當下有已點燃營火保護的 Node**；中央營地、港口或其他地點名稱本身不自帶安全效果。營火僅阻止夜間環境危害，不造成 PvP 或普通戰鬥免疫。

## 火山地牢

【核對摘要】共有**三層**，每層為**三條分支**，每層最短需要 **3 次 Node 移動**抵達該層 Boss。最底層終點是巨龍。

- 非 Boss Node：當**沒有其他島民**的地點被進入時，100% 觸發**一個**該層事件；其中一般怪物直接遭遇占 50%。
- Node 已有其他島民時，不可當作每名後來者都重新抽一份獨立事件。
- 遭遇怪物時，Node 內所有在場島民直接進入同一場戰鬥；不是由一人私有的隔離戰鬥畫面。
- Boss 屬獨立機制；離開後再次進入 Boss Node 可重新出現 Boss（依 Boss 狀態決議）；不可與非 Boss 隨機事件池混合。
- 擊敗樓層 Boss，該 Boss Node **所有仍存活的島民**獲得下一層進入資格。第二層的特殊勝利/撤退機制見 05。
- 退出地牢後，再次進入應重做樓層進度；不能把上一趟的路線推進偷留成永久捷徑。
- 正在戰鬥可**後退至來路**（不是戰鬥中直接往前穿透敵人）；**第二層黏液怪特殊禁止撤退**。
- 地牢內屍體可搬走、搜刮；不可直接掩埋或立碑；外部場景允許相應屍體處理。

## 地牢第一排的特例

第三層第一排 Node：**A1 / B1 / C1** 可能觸發火山彈；此事件只破壞一件**手持普通物品**，不破壞背包內容和所有勇者系列裝備。其他第三層 Node 不可產生火山彈。關於第三層 8% 事件權重移出其他 Node 後如何重分配，見 11。

## 特殊探索連續條件

| 地點／行動 | 條件 | 效果 |
|---|---|---|
| 夜間河流潛水 | 夜間**連續 3 次**探索，不中斷 | 獲得勇者上甲（若尚未存在/可生成） |
| 夜間岩石探索 | 夜間**連續 3 次**探索，不中斷 | 獲得勇者盾（若尚未存在/可生成） |
| 釣魚 | 特定低機率物品池 | 可能取得勇者下甲 |
| 地牢第三層火蜥蜴 | 擊殺並符合唯一存在條件 | 取得勇者劍 |

連續探索的『3 次』是**三個大行動**，因此至少 **9T**；更換行動、離開現場或跨日會重置連續紀錄。【待回查】「夜間潛水」的具體節點原 ID 與場景完整進入觸發表。

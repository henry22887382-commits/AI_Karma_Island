# 06｜地表事件、採集、釣魚與夜間危險

> 節點位置與確切地圖連線仍需原圖；不把不同區域事件假裝能在全島每個 Node 發生。數值已確定的先列出，沒有數字的只敘述存在。

## 三處椰子沙灘【定案 Q182】

- 全島有**三個椰子沙灘**。
- **每個沙灘每日新增 1 顆椰子**；每處庫存**至多 3 顆**，全島自然庫存最多 9 顆。
- 自然存放於椰子沙灘且在上限內的椰子**不會因地面過期機制消失**；只有被採集才減少。
- 每顆椰子提供 **+1 飽食**。採集是 **3T 大行動**，食用則按物品操作的小行動計時。
- **每天最多新增 3 顆，不代表每天一定新增 3 顆**；滿庫存時當日該處不再累積。

## 河流與潛水

- 普通水中探索：**普通魚 20%、名鮭魚 5%、空手 75%**（此為該動作自己的池，不能與釣魚池合併）。
- 夜間潛水額外有**5% 遭遇河流夜熊**，HP16/DEF1/SPD3/傷害3:20%、4:40%、5:30%、6:10%；其與魚獲池的先後及獨立性以原事件定義為準。
- 夜晚連續**三次**潛水，且未換行動/離開/跨天，取得**勇者上甲 DEF6**；三次大動作花至少 9T。
- 游泳行動本身**不固定扣 HP**，不能任意添加『每次下水扣 1HP』。
- 河流入口有水流推移、濕滑等強制位移或風險的事件構想，**機率與方向待回查**。

## 岩石探索

| 單次探索結果 | 機率 |
|---|---:|
| 魔法石 | **5%** |
| 寶箱 | **5%** |
| 無直接收穫 | **90%** |
| **合計** | **100%** |

- 白天探索岩石區：有 **20%** 機率 **−2 HP**。
- 夜間探索：有 **40%** 機率 **−2 HP**；另有獨立 **25%** 機率 **−1 睡眠資源**。這兩個夜間不良效果可同時發生，**不能當成互斥合計 65%**。
- 夜晚**連續 3 次**岩石探索，獲得勇者盾 DEF6；中斷/離開/跨日重算。
- 「魔法石 5%」「寶箱 5%」「空 90%」是資源抽取池；白/夜傷害是環境額外風險，**分開抽**。

使用者補交原始探索表：**森林採野莓**有益野果 **80%**，無收穫 **20%**，沒有另外列出的傷害。此動作與地牢第一層的莓果事件不同，**不能相加成同一池**。詳見 `tables/recovered_surface_actions.csv` 與 07A。

同次補交的**岩縫15%/15%/70%及15%扣1HP**屬早期摘錄。使用者已重新確認岩石資源池正式為**5%/5%/90%**，舊資源率不生效；15%−1HP也不併入既有日夜傷害風險。此次確認僅涉及資源機率，傷害與睡眠風險維持現行版本。狩獵山羊成功取得肉可補記；早期「10%扣1HP」的觸發時序待核。

### 夜間其他敵人

已知夜狼 HP12/DEF1/SPD4、夜間蝙蝠 HP2/DEF0/SPD3、河熊 HP16/DEF1/SPD3 等，詳見 05。**夜間持續環境危險每 3T 結算一次**，一晚 8 次；夜狼和夜間蝙蝠是**全部未受已點燃營火保護之 Node**的共通危險。**安全區只能由點燃營火形成**：即便地點叫中央營地、港口、紀念碑谷，沒有已點燃營火就不是夜間安全區。此安全僅針對夜間環境危險，**不排除普通戰鬥、特殊探索或 PvP**。它與主動夜間探索、潛水、移動的特殊事件機率**不是同一個抽籤**，也不重新分配地牢主事件率。

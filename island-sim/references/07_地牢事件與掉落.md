# 07｜三層地牢完整事件池與掉落

> 表中每層的各項**互斥主事件**恰好合計 100%。『50% 普通怪物』指前三種主事件合計 50%；其他事件可能**間接**引發額外戰鬥，不能偷改主池比例。事件池 CSV：`tables/dungeon_events.csv`。

## 共同抽取規則

- 進入**原本無其他島民**的非 Boss Node 後，**必定**抽取該層**一件**事件。
- 通常前三類普通怪物事件合計 **50%**。特殊事件可帶來道具、危險、強制位移或戰鬥。
- 每層獨立掉落表；普通怪與事件內的箱子/背包掉落要依其來源歸屬。
- 地牢事件物件與未開箱子生成後**72T**獨立到期，勇者系列不按此到期。
- **原始 Q149–Q150 物品表已由使用者補交**：怪物額外功能掉落率、七種容器分類權重及具體物品比例。完整復原表見 [`07A_找回的詳細掉落表.md`](07A_找回的詳細掉落表.md)，並可直接使用 `tables/monster_bonus_drops.csv`、`tables/container_category_weights.csv`、`tables/container_item_subpools.csv`。容器一次一物原文有「暫定」字樣，另標狀態。

## 非主事件直接掉落與物品

### 第一層 Boss

擊敗大金剛鸚鵡，發放通往第二層資格；最後一擊者按規則獲得**隨機一件鐵級防具**及紅、橙、黃、綠、藍五色之一的**玻璃珠**。在場仍存活的島民都能取得通行資格，不是人人各拿一套防具。

### 第二層 Boss

大貓爪無HP、DEF4、SPD6。島民普通攻擊命中後，僅ATK>4才記一次有效破防；全體共同累計5次後Boss立即主動撤退並通關第二層。最後一次有效破防者獲得**隨機一件騎士級防具**及紅、橙、黃、綠、藍、靛、紫、金八色之一的**毛線球**，同Node仍存活島民共同取得第三層資格。玩家自行撤退沿用05來路規則，與Boss主動撤退分開；未達5次離開不通關。Boss對島民攻擊20%命中，命中後原始傷害8/9各半，再扣目標總DEF。

### 第三層

- 火蜥蜴：若勇者劍無可用實體，擊殺**保證**勇者劍（唯一，攻15）。
- 火蜥蜴：其他功能掉落曾指定約 **50% 炸彈**；**本次已找回：50% 炸彈屬普通怪額外功能掉落池**；勇者劍的條件保證掉落屬獨立唯一物品機制，**不得當成50%額外勇者劍**。
- 巨龍：最後一擊者取得 **龍血 +10HP**，沒有長生不老物品。

### 其他功能道具與掉落來源

- 一次性炸彈：主目標原始傷害10、其他戰鬥參與者原始濺射6，持有人不受濺射，仍減防。
- **營火**：黏液怪 **5%**、大大水豚 **5%** 的額外功能掉落；第二層生鏽寶箱依**功能類20% × 營火在功能類5% = 整體1%**。第一層沒有營火來源。
- 紙筆、告示牌、炸彈、營火及各級普通武防的**詳細掉落比例已從使用者原表回收**，見 07A 與 CSV。文字文獻的**實際100多段文章內容**仍待回收。

## 對掉落池的工程要求

1. 區分 `event_pool`（必抽一次、合計100%）與 `drop_pool`（可為附加條件抽）；不要把 35–40% 一般功能道具掉落額外機率誤加到 100% 主事件池上。
2. 裝備唯一性是全域約束，不能只查當下擊殺者背包。
3. 掉落物先入最後一擊者背包；滿包落地，按 **72T** 過期（唯一物品例外）。
4. 所有隨機抽取保存確切種子/事件結果，供死後傳記和驗收重播。
